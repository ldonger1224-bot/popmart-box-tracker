# 抽盒机记录器手机安装说明

## 本版更新

- 不再保存整张原始截图，只保存压缩后的商品小图，避免 iPhone 本地存储被十几张图撑满。
- 启动时会自动清理旧记录里的大截图字段，释放空间。
- 商品图保留彩色，OCR 改回清晰彩色压缩图，避免名称、款式、价格被黑白处理带偏。
- 款式优先识别 `2）等待`、`1）穿针引线` 这类编号行，并排除“小盒”等干扰词。
- 金额优先读取 `¥`、`￥`、`商品金额`、`实付` 行，避免把编号误当价格。
- 批量处理每张后继续释放临时文件引用。

## 注意

- 手机上建议每次批量选择 6 张以内。
- 更新后请关闭桌面图标重新打开一次，让旧数据完成瘦身。
